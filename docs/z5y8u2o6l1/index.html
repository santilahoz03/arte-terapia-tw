如何使用肯定卡

每張卡片包含兩個部分：一個積極的肯定語，以及一個視覺任務，幫助你將那個肯定深入你的感受，而不只是你的思維。

研究表明，將肯定與創意行為（例如繪畫）結合，比單獨閱讀肯定更有效。當你畫出肯定時，你正在通過多個感官通道強化那個信念。

如何使用：

每天早晨選擇一張卡片。大聲讀出肯定語 3 次。完成視覺任務（5-10 分鐘）。在空白處記下你的想法或感受。

如果某張卡片引起強烈的抵觸感，那張卡片可能是今天最重要的一張。在那裡停留。
