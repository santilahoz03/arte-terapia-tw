如何使用這些卡片

焦慮對話卡是你與焦慮進行有意識對話的工具。每張卡片都有一個問題，幫助你更深入地了解焦慮的信息。

焦慮不是你的敵人——它是你系統中的一個信號。這些卡片幫助你解讀這個信號，不是逃避它。

如何開始：

  • 每天早晨或在感到焦慮時選擇一張卡片
  • 在卡片的空白處寫下或畫出你的回答
  • 不要評判——讓回答自然流出
  • 如果一個問題引起強烈的反應，在那裡停留更長時間

提示：

  • 列印並剪下卡片，放在你每天看到的地方
  • 建立一個每週一次的「焦慮對話」儀式
  • 在日記中記錄你的答案，以便日後回顧
