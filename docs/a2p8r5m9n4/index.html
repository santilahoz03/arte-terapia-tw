如何使用？找到今天最能引起共鳴的主題。選擇一個練習。準備好紙和筆。按照自己的節奏跟著引導進行。不需要藝術技巧——只需要誠實面對自己的意願。

如何使用本手冊

藝術治療手冊適合所有人——不論你是否有藝術基礎。問題不在於創作完美的藝術品，而在於運用創意表達來了解自己。

初學者

  • 從今天最能觸動你的主題開始
  • 每天一個練習——10–20 分鐘就足夠
  • 不要評判你的結果——過程比結果重要
  • 如果卡住了，只需重新閱讀引導說明

專業人士

  • 在個人諮商中使用練習作為創意引導
  • 在團體工作中選擇適合所有參與者的練習
  • 贈品 5（實踐與陪伴指南）包含更多專業提示

所需材料

  • 空白紙張（A4 格式最為合適）
  • 鉛筆、原子筆或簽字筆
  • 選用：彩色鉛筆、墨水筆、水彩，以及剪刀和膠水（用於雜誌拼貼）

✦ 記住：藝術治療不需要藝術技巧。它只需要你願意誠實地面對自己。沒有錯誤的答案。
